# Machine-Learning-Model
A basic machine learning model to take decisions for you

Another project made for a video.
You can either download the c++ files and compile them yourself or download the precompiled binary packages.
Weights.csv contains some weights obtained by training the model on dataset.csv.
dataset.csv contains some pretty average choices, in which will, importance and convenience are decisive.
To create another dataset just follow the same template of dataset.csv.
You will have to first run train.exe before main.exe (if you don't already have weights.csv).
